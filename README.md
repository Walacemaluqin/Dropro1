# DropPro — produção

SaaS enxuto para dropshipping com autenticação, PostgreSQL, dashboard, catálogo, pedidos, clientes, fornecedores, marketplaces e estrutura OAuth.

## Demo
- E-mail: `demo@droppro.app`
- Senha: `DropPro@2026!`

## Render
- Build: `npm install`
- Start: `npm start`
- Configure `DATABASE_URL`, `BASE_URL` e credenciais das integrações.

Nunca publique `.env` ou segredos no GitHub.
